# Project workflow

- Work locally first so changes are available for review through VS Code and localhost.
- Do not run `npm run dev`, start or stop the development server, or manage local ports unless the user explicitly asks.
- After making local changes, stop and let the user review them before any site export or deployment work.
- Do not commit, push, publish, or deploy changes unless the user explicitly approves that later step.
- Do not access the Company M: drive.
